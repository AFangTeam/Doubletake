# Timeline

把两个文件夹的照片，放在同一条时间轴上对比。

[English](README.md) · 简体中文

> 本项目以英文为准维护，这份是同步翻译。

A 轨指向一个文件夹，B 轨指向另一个。每张照片按 **EXIF 拍摄时间**落在共享的时间轴上 —— 两次拍摄是按时间先后对上的，不是按文件名排的。从两条轨里各挑一张并排看，EXIF 参数的差异会直接标出来。

## 为什么需要时间偏移

两台相机的时间永远对不齐。一台快三十秒，另一台的时区还是出厂设置 —— 两条轨就这么错开了，什么都对不上。

所以每条轨有自己的时间偏移，用 jog wheel 拖着调：拖动微调，按住 <kbd>Shift</kbd> 精细（慢 10 倍），按住 <kbd>Option</kbd> 粗调（快 10 倍）。每跨过一整秒会有一次轻触觉反馈。对齐一次，文档就记住了。

## 能做什么

- **两条轨共享一条时间轴**，按 EXIF 拍摄时间排布，空白段可折叠 —— 中间隔了三小时也不会把整个视图吃掉
- **每条轨独立的时间偏移**，用 jog wheel 调，专门对付相机时钟不一致
- **跨轨跳转** —— 从任意一张，跳到另一条轨里拍摄时间最接近的那张
- **A/B 对比** —— 两条轨各选一张，并排看
- **EXIF 差异高亮** —— 元数据浮层直接标出两张之间真正不一样的参数
- **保存对比** —— 给一组 A/B 命名存下来，之后一键跳回
- **红心收藏** —— 挑出留用的，整组导出
- **把一次对比导出成一张图**
- **在 app 里把原片移到废纸篓** —— RAW+JPG 成对时当作一张处理，两个文件一起走

## 支持的格式

JPG/JPEG · HEIC/HEIF · PNG · TIFF · RAW（ARW、CR2、CR3、NEF、NRW、RAF、RW2、DNG、ORF、PEF、SRW、RWL、SRF）

同名的 RAW 和 JPG 会被当成**一张照片**，不是两张。

## 当前状态

**只支持照片。** 扫描到的视频文件会被跳过并计数 —— 视频支持是有意暂不做的。

这是作者自己在用的工具，不是已发布的产品：没有签名版本、没有 Release，需要自己从源码编译。

## 编译

需要 **macOS 26** 和带 macOS 26 SDK 的 Xcode。

```bash
git clone https://github.com/AFangTeam/Timeline.git
cd Timeline
open Timeline.xcodeproj
```

然后 ⌘R。需要在 target 的 Signing & Capabilities 里填你自己的签名团队。

## 文档格式

这是个文档型 app。一个 `.timelinecompare` 文档是个包，里面装着 `compare.json`（轨道配置、时间偏移、收藏、保存的对比）和指向那两个文件夹的 security-scoped bookmark —— 所以重新打开文档时不用再挑一次文件夹就能拿回原片访问权。**照片本身从不会被拷进文档里。**
